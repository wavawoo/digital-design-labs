# Лабораторная работа 5: Цифровые интерфейсы - Индикатор положения энкодера

## Описание задания
Реализована система управления яркостью светодиода с помощью энкодера и OLED-дисплея для визуализации уровня яркости.

### Функциональность:
- Энкодер управляет яркостью светодиода (0–255)
- OLED-дисплей отображает:
  - Текущую яркость в процентах
  - Прогресс-бар
  - Позицию энкодера (шаги)
- Кнопка энкодера сбрасывает яркость до 0
- Ограничение диапазона (максимум за 2 оборота)

### Компоненты:
- Arduino Nano
- Энкодер (rotary encoder)
- OLED-дисплей 128×64 (I²C)
- Светодиод
- Резистор 220 Ом
- Макетная плата и провода

## Программная часть
- Используются прерывания для обработки энкодера
- Библиотеки:
  - `Wire` (I²C)
  - `Adafruit_GFX`
  - `Adafruit_SSD1306`

## Как использовать
1. Соберите схему согласно изображению
2. Загрузите код в Arduino
3. Вращайте энкодер для изменения яркости
4. Нажмите кнопку энкодера для сброса
