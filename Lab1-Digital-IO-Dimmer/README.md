# Лабораторная работа 1: Цифровой ввод-вывод - Диммер светодиода с кнопкой

## Описание задания
Реализована система управления яркостью светодиода (диммер) с помощью кнопки и ШИМ (PWM). Кнопка циклически переключает уровни яркости.

### Функциональность:
- Кнопка переключает 5 уровней яркости:
  - Уровень 0: светодиод выключен
  - Уровни 1–4: плавное увеличение яркости (50–255)
- После достижения максимума уровень сбрасывается до 0
- Реализована защита от дребезга кнопки (программный антидребезг)
- Используется ШИМ для плавного управления яркостью

### Компоненты:
- Arduino Nano
- Кнопка ×1
- Светодиод ×1
- Резистор 220 Ом ×1 (для светодиода)
- Резистор 10 кОм ×1 (для кнопки, опционально — используется `INPUT_PULLUP`)
- Макетная плата и провода

## Программная часть
- Использование `digitalRead()` для опроса кнопки
- Программный антидребезг с задержкой 50 мс
- Управление яркостью через `analogWrite()` (ШИМ на пине 3)
- Циклическое переключение уровней с помощью `map()`

## Как использовать
1. Соберите схему согласно изображению
2. Загрузите код в Arduino
3. Нажимайте кнопку для переключения уровней яркости:
   - 0 → выключено
   - 1 → низкая яркость
   - 2 → средняя яркость
   - 3 → высокая яркость
   - 4 → максимальная яркость
   - снова 0 → выключено
