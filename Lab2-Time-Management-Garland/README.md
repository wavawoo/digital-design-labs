# Лабораторная работа 2: Управление временем на Arduino - Гирлянда с плавными эффектами

## Описание задания
Реализована система управления гирляндой из 6 светодиодов с плавным включением/выключением и волновыми эффектами. Эффект реализован тремя разными способами для сравнения методов управления временем.

### Функциональность:
- Плавное волновое включение светодиодов с перекрытием
- Плавное затухание последних светодиодов в последовательности
- Циклическое движение волны вперёд и назад с паузой между циклами
- Реализация на трёх методах:
  1. **delay()** — простой, но блокирующий
  2. **millis()** — неблокирующий, позволяет мультизадачность
  3. **Прерывания (Timer1)** — точный, минимальная нагрузка на CPU

### Компоненты:
- Arduino Nano
- Светодиоды ×6 (разноцветные)
- Резисторы 220 Ом ×6
- Макетная плата и провода

## Структура кода
В папке представлены три версии программы:
- `code_delay.cpp` — реализация с использованием `delay()`
- `code_millis.cpp` — реализация с использованием `millis()`
- `code_interrupt.cpp` — реализация с использованием прерываний (TimerOne)

### Сравнение методов:
| Метод        | Точность | Нагрузка CPU | Сложность кода | Подходит для |
|--------------|----------|--------------|----------------|--------------|
| delay()      | Низкая   | Простой      | Простой        | Простые задачи |
| millis()     | Средняя  | Средняя      | Средняя        | Мультизадачность |
| Прерывания   | Высокая  | Низкая       | Сложная        | Критичные по времени задачи |

## Как использовать
1. Соберите схему согласно изображению (пины 3, 5, 6, 9, 10, 11)
2. Выберите версию кода в зависимости от целей:
   - Для простоты → `code_delay.cpp`
   - Для мультизадачности → `code_millis.cpp`
   - Для точности → `code_interrupt.cpp`
3. Загрузите код в Arduino
4. Наблюдайте волновой эффект на светодиодах
