# Лабораторная работа 3: Аналоговый ввод-вывод, COM-порт - Управление режимами светодиода потенциометром

## Описание задания
Реализована система управления режимами работы светодиода с помощью потенциометра и двусторонней коммуникацией через COM-порт.

### Функциональность:
- Потенциометр определяет три режима работы светодиода:
  1. **Непрерывное горение** (значения 0–50)
  2. **Редкое мигание** (значения 51–200, интервал 1000 мс)
  3. **Частое мигание** (значения 201–1023, интервал 50 мс)
- При смене режима в COM-порт отправляется соответствующее сообщение
- Управление режимом оповещения через команды:
  - `T` — включить оповещение
  - `F` — отключить оповещение

### Компоненты:
- Arduino Nano
- Потенциометр ×1
- Светодиод ×1
- Резистор 220 Ом ×1
- Макетная плата и провода

## Программная часть
- Чтение аналогового значения с потенциометра (`analogRead`)
- Определение режима по заданным пороговым значениям
- Управление светодиодом в разных режимах
- Работа с COM-портом (`Serial`) для приёма команд и отправки сообщений

## Как использовать
1. Соберите схему согласно изображению
2. Загрузите код в Arduino
3. Откройте монитор порта (9600 бод)
4. Вращайте потенциометр для смены режимов
5. Отправьте команды:
   - `T` — включить оповещение
   - `F` — выключить оповещение
