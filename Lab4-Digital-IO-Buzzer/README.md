# Лабораторная работа 4: Цифровой ввод-вывод - Управление уровнем на светодиодной линейке со звуковой индикацией

## Описание задания
Реализована система управления количеством горящих светодиодов с помощью кнопок и звуковой индикацией (buzzer) при попытках выйти за допустимые пределы.

### Функциональность:
- Две кнопки: **увеличение** и **уменьшение** количества горящих светодиодов
- Три светодиода образуют линейку индикации
- Звуковая сигнализация при попытках:
  - Увеличить уровень, когда все светодиоды уже горят
  - Уменьшить уровень, когда все светодиоды погашены
- Использование прерываний для обработки нажатий кнопок

### Компоненты:
- Arduino Nano
- Светодиоды ×3
- Кнопки ×2
- Активный buzzer ×1
- Резисторы 220 Ом ×3 (для светодиодов)
- Резисторы 10 кОм ×2 (для кнопок)
- Макетная плата и провода

## Программная часть
- Используются прерывания для кнопок (`FALLING`)
- Управление светодиодами через цифровые выходы
- Генерация звуковых сигналов с помощью `tone()`
- Защита от дребезга кнопок программным способом

## Как использовать
1. Соберите схему согласно изображению
2. Загрузите код в Arduino
3. Нажимайте кнопки:
   - Кнопка на пине 3 → увеличить уровень
   - Кнопка на пине 2 → уменьшить уровень
4. При достижении минимума/максимума прозвучит предупреждение
